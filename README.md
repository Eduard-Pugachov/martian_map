# A Walk through Jezero Crater

NASA Space Apps Challenge 2026, "Interplanetary Survival Guide: Martian Map". Solo project by Eduard Pugachov.

Astronauts walking on Mars must avoid steep slopes, but slope maps need stereo elevation models (DTMs), which exist
for only a few sites. This project predicts slope hazard from a single HiRISE image and plans safe walking routes
from it, so routes can be planned where no DTM exists.

Demo slides: https://drive.google.com/file/d/12ANw-0bvfPQVayayq5glP9yKzlYluFNZ/view?usp=sharing

## How it works

1. **Hazard U-Net** (`smp.Unet`, ResNet-34 encoder): labels each pixel of the 1 m HiRISE orthomosaic as safe
   (< 10°), caution (10–25°) or hazard (≥ 25°). Labels come from slope on the HiRISE DTM; at run time only the
   image is used.
2. **Landforms:** the pretrained DoMars16k classifier, run on the CTX mosaic, adds cost for dunes, rough terrain
   and crater fields.
3. **Routing:** A* (`skimage.graph.route_through_array`) on a 5 m cost grid. Risk-aware rule: a cell counts as
   hazard if the U-Net's hazard probability is ≥ 0.1 (chosen on a separate validation region).

Train, validation and test are separate spatial blocks with a 300 m buffer; the 6 × 6 km test region is unseen.

## Results (unseen test region)

| Model | Mean IoU |
|---|---|
| U-Net (image only) | **0.547** (safe 0.86, caution 0.42, hazard 0.36; hazard recall 71%) |
| Image-gradient baseline | 0.288 |
| Always "safe" | 0.283 |

200 random walks of 2–6 km, each scored on the true DTM slope:

| Route | Crosses a true hazard (95% CI) | Median extra effort vs DTM route |
|---|---|---|
| True slope classes (needs a DTM) | 0% (0–1.9) | 10.1% |
| **Risk-aware U-Net (image only)** | **5.5% (3.1–9.6)** | 15.2% |
| Plain U-Net | 21.5% (16.4–27.7) | 15.8% |
| Landform only (no slope info) | 77.5% (71.2–82.7) | 13.5% |

**Limitations:** single-image slope depends on lighting. On west-facing slopes the hazard IoU drops to 0.14. The
model was trained and tested in one crater, and 5.5% of routes still cross a hazard: a planning aid, not a guarantee.

## Run the app

```
pip install gradio numpy pandas matplotlib rasterio scipy scikit-image pyyaml
python app/app.py
```

Open http://127.0.0.1:7860. The app runs on CPU from the precomputed layers in `app/data/layers.npz`. Click a start
and a goal, or press "Demo route", and switch between DTM mode and DTM-free mode.

Rebuilding everything from the raw data (multi-GB downloads, GPU training) is described in `PLAN.md`; settings are
in `config.yaml`; tests run with `pytest`.

## Data

- Mars 2020 TRN HiRISE DTM and orthomosaic of Jezero Crater (USGS), https://doi.org/10.5066/P9QJDP48
- Mars 2020 TRN CTX orthomosaic (USGS), https://doi.org/10.5066/P9GV1ND3
- DoMars16k dataset and pretrained models, https://doi.org/10.5281/zenodo.4291940
